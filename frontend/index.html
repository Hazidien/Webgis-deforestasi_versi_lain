WEBGIS PROJECT

WebGIS Deforestation

by Hazidien Ramadhan Utomo

PurposeInteractive GIS for screening forest extent and long-term forest-area change using Landsat imagery processed with Google Earth Engine.

How to use this WebGIS

1. Module

The current module is Deforestation. It applies the forest-extent workflow based on the supplied Landsat/VI method.

2. Benchmark period

1990 → 2020 is fixed for this module. The workflow evaluates 1990, 1995, 2000, 2005, 2010, 2015 and 2020.

3. AOI

Draw a polygon/rectangle directly on the map, or upload a Shapefile ZIP containing .shp + .shx + .dbf + .prj. Maximum upload size is 20 MB.

4. RUN ANALYSIS

Submits the AOI to the FastAPI backend, initializes Earth Engine and runs the remote-sensing workflow.

5. CLEAR AOI

Removes the AOI, result layers, map legend and previous result cards so another area can be analysed.

6. Result

After a successful run, the interface reports 2020 forest area, 1990–2020 area change and forest cover percentage.

7. Map layers

Use the Layers control to switch result overlays and compare benchmark outputs on the map.

8. Downloads

PDF REPORT provides a summary report. DOWNLOAD GEOTIFF provides the generated raster download when available.

Current analysis method

Landsat 4/5 or 8/9→Cloud mask→Median ±1 year→VI→VI > 0.70→Forest area

VI = (NIR − SWIR) / (NIR + SWIR). The output is a screening indicator, not a certified land-cover classification.

Map controls

Use the drawing tools to create the AOI. Use Layers to switch overlays and the zoom controls to change scale. The sidebar can be collapsed and reopened at any time.
