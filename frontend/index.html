WEBGIS PROJECT

WebGIS Deforestation

by Hazidien Ramadhan Utomo

PurposeInteractive GIS for forest screening and forest-change analysis using Landsat imagery processed with Google Earth Engine.

One run = one analysis

Choose one module only. RUN executes only the selected engine; Deforestation and NDFI Change Detection are never executed together in the same request.

Available modules

Deforestation

Long-term forest extent screening using the supplied workflow: Landsat 4/5 + 8/9, median ±1 year, VI = (NIR − SWIR)/(NIR + SWIR), forest rule VI > 0.70, with fixed benchmark years 1990–2020.

NDFI Change Detection

Two-date SMA/NDFI workflow based on the supplied Course 1 and Course 2 material. Time 0 and Time 1 are two user-selected observation dates; each is expanded to a one-year median Landsat 8 window, then NDFI Change is calculated and classified.

NDFI dates

The interface intentionally asks for only two dates: one earlier observation (Time 0) and one later observation (Time 1). The application creates the compositing windows internally, so users do not need to enter four start/end dates.

AOI & results

Draw a polygon/rectangle or upload a Shapefile ZIP containing .shp + .shx + .dbf + .prj. Results, map layers, PDF report and GeoTIFF belong only to the selected analysis run.

Why separate the modules?

The two methods answer different analytical questions and have different inputs and outputs. Separating them prevents unnecessary Earth Engine computation and keeps each result traceable to exactly one method.
